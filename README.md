# 旧衣回收灵感

铛铛一下的旧衣回收灵感墙。

卡片正面展示品牌效果图，点击卡片查看背面的灵感来源。页面采用 3:4 卡片和响应式五列布局。

视觉规则：除非另有指定，站点背景与卡片留白统一使用纯白色，不使用米黄、暖灰或其他带色背景。

公开网站：<https://daafffodil.github.io/dangdang-inspiration-wall/>

## 本地预览

```bash
npm install
npm run dev
```

## GitHub Pages

```bash
npm run build:pages
```
